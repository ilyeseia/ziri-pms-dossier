# PRÉSENTATION COMMERCIALE ZIRI.PMS

## 1. ZIRI.PMS en résumé
Property Management System algérien, version 2.6.5, basé sur Frappe.
Couvre réception, réservations, hébergement, caisse, POS, housekeeping, banquets.

## 2. Points forts vérifiés
- Localisation DZD, RC/NIS/AI/NIF
- POS avec transfert chambre réel
- Tableau de bord direction
- Réservation en ligne opérationnelle

## 3. Limites transparentes
- Smart Access dépendant équipement
- RH/Pointage partiel
- Configuration initiale nécessaire

## 4. Proposition de valeur
Réduction des erreurs, traçabilité complète, un seul compte client.
